# Aika BlazBlue movelist

Aika stays a karate zoner. Her Drive is **Resonance Nail**. 5D throws a straight nail, 2D a low nail, j.D a nail angled down, and 6D detonates the nails already out. She holds 5 nail stocks. Overdrive makes nails free. Astral Heat is off.

Classic Aika is unchanged. This kit runs only when the scheme is BlazBlue and both fighters have a profile. An Aika mirror is both sides set to C02, then `SettingsPanel.SetControlScheme(ControlScheme.BlazBlue4Button)`. Against Akio, both profiles exist, so that match is BlazBlue too.
